# ⏰ O'clock

O'clock est une application web de gestion du temps réalisée en HTML, CSS et JavaScript.
Fonctionnalités

- Horloge en temps réel  
- Minuteur  
- Chronomètre  
- Réveil avec message

 Structure du projet

oclock/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Technologies utilisées

- HTML  
- CSS  
- JavaScript  

Aucune librairie externe n’est utilisée.
